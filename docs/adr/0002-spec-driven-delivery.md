# ADR-0002：Spec 驱动的增量开发

- 状态：采用。
- 日期：2026-10-13。

用户要求先维护文档，再开发。项目使用编号 spec 承载可独立验收的增量，每个增量包含需求与 AC 编号、实现方案、任务和契约；完成后记录验证证据并更新产品文档。

原始讨论和网上资料作为设计参考，外部资料保存在 `resources/` 并注明来源与版本。常规实现按已确定 spec 自主推进，产品范围、身份边界和破坏性接口变化需澄清。

首个增量只交付原生 Python SDK 与本地 Trace，之后先建立 Collector 的 OTLP spec，再开发服务端。仍遵守 Foundation 中的模块边界和渐进路线，不将局部可运行示例称为完整平台 MVP。
