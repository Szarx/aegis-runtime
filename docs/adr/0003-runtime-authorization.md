# ADR-0003：本地工具授权与观测分离

日期：2026-10-18。状态：SPEC-009 采用。

先用宿主构造绑定身份和不可变策略做精确三元组授权；deny 优先，未匹配或求值失败默认拒绝。在执行工具入口接入 Runtime，不根据工具参数、模型文本或遥测身份授权。Policy 纯标准库模块；Runtime 依赖 SDK，SDK 核心不反向依赖控制模块。

授权与观测采用不同故障行为：策略不可用不能放行，遥测不可用不能绕过拒绝或重跑已允许工具。异步遥测可能丢失，因此本轮只记录决策信息，不称为持久/不可篡改审计。Collector 不使用这些上报字段认证请求或进行二次授权。

受控调用尝试复用 Tool Span，但使用独立治理 mapping，明确 denied 不表示工具执行。旧 SDK permission 标签继续仅观测。暂不引入身份服务、远程策略、通配符、审批或恢复；后续 require_approval 必须先冻结动作/参数/身份绑定、持久化与失联失败行为。

同进程代码可直接访问原函数，宿主仍须信任其代码并接入所有真实工具入口；不声称沙箱。标准依据与实际边界见 [研究笔记](../../resources/notes/runtime-policy.md)。
