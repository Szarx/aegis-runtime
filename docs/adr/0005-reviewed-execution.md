# ADR-0005：永久消费领取与显式同步恢复

日期：2026-10-20，SPEC-011采用。

审批准备的summary/HMAC不足以审阅真实参数，也没有执行协调。新增独立ReviewedTool和协议：宿主显式选择完整JSON参数披露，按签名补默认值，冻结独立实参快照，绑定身份/策略/工具版本与摘要。人工批准是本地allow之外的附加条件，不改写旧策略或旧准备记录。

服务端使用新关联表和第三种执行凭证，单事务锁定批准及执行行，未过期且绑定一致时available→claimed。任何重复领取失败；不使用到期可重新执行的租约，因为崩溃后无法判断外部副作用是否已发生。完成确认单独记录completed/failed，相同结果幂等；确认丢失保持unknown，不重新运行工具。

客户端采用保守剩余时效、无网络/业务重试，并在进入函数前检查策略；返回原对象与确认状态，业务异常身份保持。代价是领取后未开始执行也会永久消费，需人工调查未知结果；跨外部系统恰好一次并未解决。固定角色、可信宿主/数据库管理员、显式工具版本不构成生产身份或沙箱。

首版仅普通同步具名JSON参数。异步取消、图checkpoint恢复和策略require_approval分支分别定义后续spec，避免把一次本地调用误称为完整Agent恢复。新旧协议与页面明确分离，旧010批准仍绝不可执行。详见 [接入](../reviewed-execution.md) 与 [规格](../../specs/011-reviewed-execution/spec.md)。
