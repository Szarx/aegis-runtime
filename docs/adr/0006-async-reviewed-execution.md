# ADR-0006：原生异步审批恢复与取消

日期：2026-10-20。状态：采纳，对应 [SPEC-012](../../specs/012-async-reviewed-execution/spec.md)。

沿用011永久消费claim与明确工具版本，不为async新增服务器状态或隐含执行入口。将签名、JSON快照、策略和payload准备提为公共纯逻辑；同步ReviewedTool仍拒绝async，新AsyncReviewedTool只接收普通async def。原生await让宿主保留任务所有权和Agent上下文。

HTTPX以reviewed-async extra提供，导入模块不加载HTTPX；构造客户端才检查依赖。原生异步网络避免取消后仍在线程运行的阻塞请求；但取消仍不能撤销服务端已提交事务，因此领取响应丢失保持未知，绝不释放/重领。连接由异步上下文关闭，HTTPX阶段超时之外增加完整请求期限。

取消贯穿原任务，函数已开始时不把取消当成failed确认；complete期间可能已经提交，保留这种不确定性。成功确认失败仍保留返回对象，业务异常确认故障仍保留原异常，新的任务取消优先传播。库不创建孤立补偿任务，不屏蔽取消，不接管工具自身创建的后台任务。

代价是保守放弃部分尚未执行的已领取动作；需要宿主显式查询和人工处置，无法自动恢复未知副作用。关闭中断时保留再次清理入口，但不再允许业务请求。图checkpoint和多进程恢复另行冻结契约。
