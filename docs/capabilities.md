# 当前能力与限制

当前基线是 SPEC-001–049 与 [050 整理](../specs/050-public-preview/tasks.md)。历史 SPEC 中的“尚未实现”是当时状态；以下为当前范围，不代表所有框架或生产保证。

| 层 | 可运行范围 | 主要限制 |
| --- | --- | --- |
| SDK | 原生同步/异步 Agent / Tool，JSONL / OTLP，有界队列与诊断 | 显式接入；内存队列异常退出可丢失；装饰器不支持普通生成器 |
| 模型 | OpenAI Chat/Responses 支持矩阵、DeepSeek Chat，同步/异步和流 | 真实 DeepSeek 仅 005 限定验收，真实 OpenAI 未验收；无内部思维、费用估算或首 Token 延迟保证 |
| 图 | LangGraph 四类显式调用；单根审批中断、本机 SQLite 跨进程恢复 | 不自动全节点投影；无多机 checkpoint、任意多中断或跨系统恰好一次 |
| Runtime / Policy | 显式工具、宿主身份、三类决策、配置 v4、同步/异步 | 宿主可绕过；不是用户认证；无通用风险评分、注入检测或沙箱 |
| 审批 | 参数/版本/身份/策略绑定，独立人工决定、宿主单次领取并报告 | 批准不执行；完整参数会持久化；未知不可自动重试，尚无统一业务对账工作台 |
| Collector | Aegis OTLP 映射、去重、持久查询、治理/审批，迁移 1–4 | 非通用 OTLP 接收器；静态 token，无多租户/RBAC、数据保留/备份管理或不可篡改审计 |
| Dashboard | 轨迹/树/时间线、节点深链、用量覆盖、耗时、安全事件与审批队列 | 大 Trace 整体加载；只含已接收数据；无完整跨 Run 会话模型 |
| 运行健康 | 显式心跳、活动 Trace 和采集计数、45 秒失联 | 单 Collector 进程内存，重启清空；活动是最后快照，失联不等于业务失败 |
| 导出/回放 | 治理 JSONL/CSV、摘要核验、离线候选策略比较 | 哈希不是来源认证；分页不是数据库快照；不重执行原工具 |

## 如何解读验收

模型响应与业务工具多数采用合成服务边界，框架本身使用真实 LangGraph / 官方客户端。外部模板保留固定原图、替换两个服务边界，不声称生产 Agent 或新用户五分钟体验。见 [模板配方](../examples/external_react_agent/README.md)。

计数是测试方法数，不是独立用户、场景总数或安全等级。历史记录区分继承回归和完整重跑。最新统一结果在 [050](../specs/050-public-preview/tasks.md)，本机原始日志不随仓库发布。

先本地跑通 [快速开始](quickstart.md) 与 [部署](../deploy/docker/README.md)，再给自己的 Agent 增加观测。拦截/审批用合成操作逐项验证。后续优先事项见 [路线图](../ROADMAP.md)。
