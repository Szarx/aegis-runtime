# Dashboard 工作台设计

029将列表、详情、两类审批和安全事件统一为中性深色数据工作台。去掉宣传区、装饰编号和空指标；自绘SVG、细边框、克制标题和语义状态色。仅显示后端实际返回的数据，当前页统计标明范围；Token未知和无模型调用继续分开。没有新依赖、CDN或远程字体。

窄屏侧栏保留全部导航，表格在容器内横滚。已有标签、状态文本、键盘焦点、取消请求和独立审批凭证保持。批准仍必须确认完整参数；样式调整不扩展审批权限、不执行工具。连接、加载、空记录与认证错误使用同一组件语言。

参考[视觉研究](../resources/notes/frontend-design.md)，视觉验收见[029](../specs/029-dashboard-design/tasks.md)，交互验收见[030](../specs/030-dashboard-workflows/tasks.md)。

审批列表支持当前页搜索、状态筛选与状态计数；不查询全部服务端记录，页边界和全量total明确区分。默认折叠条目，展开单条后核对参数。收起、换项、筛选、刷新和断开清除参数确认，批准仍需重新勾选；决定之后刷新，页面不领取或执行工具。

Trace时间条件与事件ID/时间条件放在更多区域，折叠不会删除已填值。条件数仅显示已应用状态，草稿修改不改变当前结果说明，清空恢复全部条件。无模型的详情省去空用量卡；有模型仍分别显示已知/未知Token。Trace/Span/Parent ID可点击复制，仅在当前操作后写入剪贴板，失败时提示手动选择，不复制凭证。

031增加节点查找与Agent/LLM/Tool/异常视图筛选。筛选保留原深度与关系诊断，不重执行节点、不改变完整Trace统计或时间轴范围。节点按钮组只有一个Tab入口，↑/↓和Home/End选择并聚焦可见节点。无结果时可重置。顶部标准/紧凑切换只在当前页面生效，刷新恢复标准；树行高与时间线同步。见[031验收](../specs/031-trace-reading/tasks.md)。

032提供统一前端质量入口，检查测试/类型/构建及产物预算，并通过本机生产preview验证编译后的页面。开发热更新、构建成功和实际页面验收分别记录；没有把本机结果声明为远端CI或生产部署。操作与限制见[Dashboard说明](../dashboard/README.md)。

033补齐异步页面加载/失败恢复。页面模块出错时提示显式重载，并说明会清除当前会话凭证；不自动循环重试。Trace同条件刷新暂时保留旧结果时明确标注，新条件/翻页先清旧结果。页面更新时间只表示这次查询完成时间，不表示Collector持续健康或最新事件已到齐。审批尚未载入的数量显示横线，未知不按零处理。见[033验收](../specs/033-dashboard-states/tasks.md)。

034提高偏暗辅助文字的对比度，小型复制/密度/文本按钮至少26px高，确认标签32px高；继续保留文字状态与键盘焦点。受测tokens、实际尺寸和覆盖边界见[034](../specs/034-dashboard-accessibility/tasks.md)，不等于完整无障碍认证。

036在事件表旁提供显式本页JSONL/CSV，范围、精度和表格解释限制见[事件指南](security-events.md)。不后台查询全量或替代021排查包。

037把两种查询表单放入原生可开关面板：首次显示时桌面展开、760px及以下收起；之后开关由用户决定，窗口变化不强制覆盖。面板保持已应用数量，草稿隐藏后仍存在，不自动提交。Trace移除重复占位指标，用量总数/维度覆盖保持可见，长统计解释单独展开；执行链更早进入首屏。实际几何与完整手机查询操作见[037验收](../specs/037-dashboard-hierarchy/tasks.md)。

038审批增加本页原始/待审核优先/到期升序，重置视图同时清搜索/状态/排序。排序和筛选一样清除展开项及参数确认；不跨页查询。卡片显示完整本地到期日期，查询完成时间明确标为上次快照，不倒计时或用浏览器时钟改变服务端状态。展开记录中Action可复制，HMAC/策略摘要可单独展开，完整参数/工具版本/确认保持直接呈现。真实两种收件箱和窄屏范围见[038](../specs/038-review-reading/tasks.md)。

039支持具体节点的深链：`#/traces/<trace_id>?span=<span_id>`。树、时间线和键盘选择会替换当前hash，不为每次节点点击添加历史项；只切换同Trace节点时复用当前详情，不重新查询。节点视图筛选保持；外部定位到其他节点会显示完整链路并选中目标。指定节点未收到时提示并保留已接收内容，不当作有效的新节点。多余/重复/非法参数走无效地址，不能作为Collector路径。

节点详情中的“复制节点链接”只在点击后写入剪贴板，链接只保留页面origin/path和规范Trace/Span，不复制页面search、账号信息或会话凭证。链接包含标识，应按查询数据保管；打开链接仍需自己的Collector访问权限，重载后重新连接。复制失败时显示可手动选择的规范链接。操作与真实异步/窄屏证据见[039](../specs/039-trace-node-links/tasks.md)。

040在执行链底部增加默认收起的调用耗时排行，从完整已接收Trace派生最长20个模型/工具Span，保留精确排序、0ns和无效值排除说明。占Trace时长只是近似比例，调用可能重叠，不能相加当关键路径。定位操作清除节点筛选、选中并聚焦树节点，复用039链接和已加载详情。使用与计时口径见[排查指南](trace-reading.md)，实际证据见[040](../specs/040-call-duration/tasks.md)。

SPEC-043将Trace/安全事件已应用查询与页码保存在规范地址，标题栏提供复制，UTC边界与重新认证/历史导航保持；窄屏表格增加绘制隔离，避免整页横向滚动。见[查询链接指南](query-links.md)。

SPEC-044补全关联排查闭环：事件链接选择对应节点，详情的返回链接恢复来源查询与分页；只接受两列表来源，独立复制节点省略查询元数据。加载/错误状态同样能返回，旧地址保持。见[044记录](../specs/044-trace-return/tasks.md)。
