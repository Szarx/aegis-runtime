# 复制并恢复列表查询

执行追踪与安全事件列表支持“复制查询链接”。链接包含已应用条件和当前20条分页位置；编辑表单草稿后须先应用，未应用内容不会进入链接。复制操作复用已有反馈，失败时显示可手动选择的规范文本，不会为复制另发查询。

应用、清空及翻页都会更新地址；浏览器前进/后退恢复条件、页码与表单。执行追踪进入详情后用浏览器后退返回原列表查询。刷新、独立窗口或新会话打开链接后，需要重新提供当前Collector凭证；地址本身不能授予访问权限。鉴权探测通过后按当前合法地址读取数据，旧请求取消或迟到不能覆盖新地址的结果。

时间边界在地址中保存为UTC ISO毫秒，例如本地2026-10-25 12:34:56.123在上海时区对应2026-10-25T04:34:56.123Z。打开后表单按浏览器当前时区显示；不修改时间再次应用会保留原绝对边界，包括夏令时重复小时。主动编辑时间则按当前浏览器的本地时间解释。已有接收/存储数据的原始纳秒精度没有改变，筛选表单仍只提供毫秒边界，不把它当作纳秒筛选器。

地址只接受两列表的固定字段与20的整数倍offset（0..10000）。未知/重复/空值/非法编码/过长字段、错误ID/枚举/时间和反向区间均显示“查询地址无效”，不会退化为查询全部数据。点击“清空地址条件”回到合法的空条件列表。旧无参数地址、Trace/Span节点链接和审批地址继续使用。

查询链接会包含上报身份、工具、服务、Action/Trace标识及时间等已应用查询元数据，请按工作区范围分享。复制会删除来源地址的userinfo、原search与hash，并仅生成白名单查询；不包含token、审批凭证或未应用草稿。凭证继续只在内存中，不写入浏览器持久存储。不要在筛选字段中填写秘密。

链接保存的是查询条件而非结果快照。新数据会改变匹配数和分页边界，旧链接的页码可能为空；通过清空/重新筛选或上一页继续排查。窄屏标题操作可换行，宽表格只在容器内横向滚动，键盘仍可访问复制与刷新。

设计参考[Grafana内部链接](https://grafana.com/docs/grafana/latest/visualizations/dashboards/share-dashboards-panels/)中的状态保留与独立授权模式；Aegis当前没有公开共享、短链接服务或服务端保存查询。完整行为及真实页面证据见[043验收](../specs/043-query-links/tasks.md)。

## 从详情返回原查询

从两列表打开Trace时，详情地址可携带return参数，保存已应用的来源查询和页码。安全事件的“查看Trace”还会选中该事件对应Span。详情顶部按来源显示“返回安全事件”或“返回执行追踪”；点击可恢复原条件和页码，加载与详情查询失败时也能返回。节点选择、键盘导航和排行定位保留来源，刷新或独立会话认证后继续有效。链接是当前查询，不保证历史结果页保持不变。

return只接受本站两类列表的白名单hash地址，沿用043的条件/UTC/页码校验；不接受外部网址、审批路径、嵌套详情或未知参数。无效来源使整个详情地址无效，不请求对应详情。无来源的旧Trace/Span地址默认返回基础Trace列表；审批页面原有Trace链接仍保持旧行为。

浏览器当前地址包含来源查询元数据；如需只分享节点，使用节点详情的“复制节点链接”，生成的链接仅包含Trace/Span，不带return、来源查询或凭证。来源上下文不会授予访问权限。旧查询链接和普通浏览器后退仍可使用。具体证据见[044验收](../specs/044-trace-return/tasks.md)。
