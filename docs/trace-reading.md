# Trace 节点与调用耗时排查

先按[部署指南](../deploy/docker/README.md)启动平台并连接Dashboard。需要合成数据时可运行[演示命令](dashboard-demo.md)，不需要真实模型凭证。页面只展示已接入、成功上报且当前已接收的数据。

## 找到具体调用

执行追踪列表支持Agent、Service、状态和时间范围。展开查询面板后编辑条件，点击应用才会查询；收起不会清空草稿。窄屏首次显示时查询面板默认收起。点击一条Trace进入详情。

详情中的节点名/服务/ID搜索和Agent、LLM、Tool、异常视图只影响链路展示，完整Trace用量和耗时排行保持。树节点支持↑/↓、Home/End；选择节点后，右侧显示服务、父子ID、耗时及可获得的模型用量/治理决策。

## 从轨迹查到审批结果

执行追踪列表分开显示 Trace 状态与已接收的治理信号。「曾请求人工审批」描述曾经发生的请求，即使工具后来执行过，历史信号也不会改写。「审批后工具已返回」描述已接收的执行 Span，审批记录中的「已确认完成」才表示宿主已提交完成确认。

详情默认打开轨迹。时间总览有 Agent、模型、工具和治理四条带，点击标记可选中对应步骤。列表按开始时间和 Span ID 排序，↑/↓、Home/End 可跨页定位，时间总览按整条 Trace 的尺度展示本页步骤。可按规则或 Action ID 搜索。工具异常、拒绝与审批快照在步骤行直接显示。切换「树视图」可检查调用层级。

选中需人工审批的步骤，点击「查看此动作的审批状态」。执行审批使用独立的 reviewer token 精确查询 Action ID，显示审批决定及执行确认，即使目标早已不在普通审批首页。用「返回原轨迹节点」继续排查。

首次打开可从连接页选择「打开合成轨迹演示」，或直接打开 Dashboard 的 `/#/demo`。请求轨迹、审批结果和恢复轨迹共享一个合成 Action。无需 Collector、凭证或 LLM。正式接入与页面部署参见[快速开始](quickstart.md)。

## 从耗时排行定位

在执行链面板底部展开“调用耗时排行”。排行只包含当前Trace已接收的模型与工具Span，排除Agent根节点，按记录耗时降序展示最长20个；相同Span ID只保留首次记录。数量是当前已接收调用数，不能推断SDK内部重试或未接入调用。

耗时按结束纳秒减开始纳秒计算，排序全程使用BigInt。0ns保持0；悬停耗时可查看完整纳秒。无效时间/ID显示排除数量，不按0计算。没有模型或工具时显示空状态。

占Trace时长是近似比例，分母为这条Trace的已接收时间范围。极小正比例显示`<0.01%`，Trace时长为0时显示未知；异常数据超过100%时保留数值，条形仅限制视觉宽度。调用可能嵌套、并发或重叠，不能将排行耗时/比例相加当总执行时间或关键路径。

点击“定位”会清除节点视图筛选，选中并聚焦对应树节点，同时更新地址中的Span定位。这个操作复用已加载详情，不再查询Collector，更不会重新执行工具或模型。完整用量、原始时间与关系诊断保持。

## 保存节点定位

点击节点详情的“复制节点链接”，可复制`#/traces/<trace_id>?span=<span_id>`形式的完整页面地址。链接去除原页面查询参数/账号信息，只保留页面路径与规范标识。接收者仍需自己的Collector访问权限；页面重载后需重新连接。ID本身也应按查询数据保管。

指定Span尚未收到时，页面会提示并展示已有链路，不伪造节点或额外查询。多余、重复或非法参数不被转发到Collector。复制失败时可手动选择规范链接。

## 时间与用量口径

模型调用的Span耗时描述Agent侧可观测的调用生命周期。流式调用通常包含消费直到完成、提前关闭或取消的过程，可能包含客户端/网络和SDK内部重试等待。Span结束时间先确定，再进入处理器/导出器，因此本Span的导出等待不计入自身记录耗时；外层Agent区间仍可能包含子调用、其他处理和等待。它不是模型服务端纯推理时间，也没有单独测量首Token延迟。

输入/输出用量分别显示完整度：缺失仍为未知，实际0保留0；费用不估算。详见[用量说明](trace-usage.md)。Aegis服务本身无需LLM，实际模型调用仍由Agent发起。

验收范围见[039节点深链](../specs/039-trace-node-links/tasks.md)和[040调用耗时](../specs/040-call-duration/tasks.md)。当前未验收大规模Trace性能、关键路径分析、模型服务端指标或更多浏览器兼容性。

SPEC-044：从执行追踪/安全事件列表进入详情时保留来源查询，事件会定位对应Span。详情/加载/错误状态均可显式返回原列表条件和页码；节点切换保留来源，独立节点复制仍省略来源。见[查询返回指南](query-links.md#从详情返回原查询)。
