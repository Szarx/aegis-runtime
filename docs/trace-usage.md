# Trace 模型用量汇总

执行详情新增“模型用量汇总”，按当前Trace已接收的模型Span计算，不改变节点级用量展示。无需新增服务配置、模型凭证或数据库迁移。

只计chat / CLIENT / aegis.genai.v2节点，同一trace/span ID计一次；Agent、工具、其他Trace或其他映射上的同名属性不参与。不同模型/Provider的Token可相加为观测计数，不代表相同定价或统一tokenizer。

| 情况 | 展示 |
| --- | --- |
| 所有已接收调用都有输入用量 | 精确输入总数及N/N覆盖 |
| 某次调用缺输入、输出完整 | 输入未知及已知数/N；输出仍显示完整总数 |
| 返回的用量为0 | 显示0，保留有效数据与缺失值的区别 |
| 没有已接收模型调用 | 无模型调用，不把Token显示为0 |
| 某次调用异常/取消但带有效用量 | 保留其已上报计数，不因状态推断费用 |

所有解析/累加均为BigInt，避免超过JavaScript安全整数时舍入；单项仍按既有协议限制到有符号64位，总和可以超过该范围。长数字换行显示，不截断或改为近似科学记数。

覆盖率只相对于当前已接收模型节点，不能证明Trace已结束/到齐，或覆盖SDK内部HTTP重试、未接入调用。后续Span到达后重新加载详情才会更新。输入输出分别完整才分别显示总数；不显示部分和冒充完整总量。

费用保持“未估算”，不是账单功能，也没有推导模型服务端推理时间。完整行为和验证见 [SPEC-019](../specs/019-trace-usage/tasks.md)。
