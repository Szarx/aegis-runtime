# SPEC-003：Trace Dashboard

- 日期：2026-10-15。
- 状态：契约确定；实现和验证见 [tasks.md](tasks.md)。
- 范围：Phase 1A 原生 Agent → SDK → Collector → PostgreSQL → Dashboard 可视化闭环。

## 用户场景

开发者启动本地平台并运行原生示例后，在浏览器中找到成功/失败 Trace、查看关联的 Agent / Tool、定位异常类型和时间关系。页面只查询已有数据，不执行工具、重发 Agent 或提供策略审批。

## 行为与数据

1. Vue 3 / TypeScript / ECharts。列表提供 Agent、Service、状态与开始时间范围筛选、每页 20 项、前后翻页、手动刷新。筛选应用后 offset 归零；新请求覆盖旧请求时，旧响应不得更新界面。
2. 使用 SPEC-002 列表/详情接口，展示完整 Trace 状态、时间、时长和 Span 数。列表计数是当前筛选结果；当前页指标清楚标识范围，不伪装全局统计。
3. 详情展示树、同一时间原点的时间线和选中 Span 的 metadata / 异常类型。多个根、缺失或外部父节点明确标识，环形/自父引用不会无限递归或漏节点；异常关系提示数据不完整。
4. OTLP 时间戳已超过 JavaScript 安全整数；API v1 不改为字符串。浏览器读取 response.text，以无损 JSON 解码和 bigint 处理 Unix 纳秒、duration 及事件时间。先减整数原点，再换算图表相对坐标。原始纳秒可查看，日期仅格式化到毫秒；0 时长也可选中，不伪造耗时。
5. UNSET 显示“已完成”，ERROR 显示“异常”，保留原始状态可查看。未采集 Token/成本显示“未采集”，permission 只标为“权限元数据”。不展示模型内部思考或补造 LLM 节点。
6. Bearer token 在连接表单输入，仅保存在页面内存；刷新页面需重新输入。不得出现在 URL、local/sessionStorage、构建文件、日志或遥测中。未配置服务端 token 的本地服务可留空。请求只发向同源 /api；开发和 Compose 通过反向代理访问 Collector，不增加宽泛 CORS。
7. 显示加载、未连接、空数据/无匹配、401、404、超时/失联、其他错误与重试。切换连接清除已有数据并取消请求；请求有 10 秒上限。错误只显示固定消息，不回显请求响应载荷或 token。
8. hash 路由支持 Trace 详情直达及浏览器前后导航；认证未完成时保留目的路径。离开详情取消请求，列表筛选状态在同一会话内保留。无自动轮询。
9. 中文为主要界面，暗色开发者工作台。键盘可操作列表、树和详情，颜色同时配文字；320 px 起可用，宽屏列表与详情清晰分区。图表提供等价的可点击 Span 列表，无需依赖 canvas 进行导航。
10. 本地开发启动说明、锁文件、前端静态构建和 Compose Dashboard 服务一并交付；公开端口绑定回环，代理不内置 token。未触发外部发布。

## 验收

| 编号 | 条件 |
| --- | --- |
| AC-301 | 使用真实 Collector / PostgreSQL 和原生 CLI，UI 可定位成功和失败 Trace，各有正确的两个节点 |
