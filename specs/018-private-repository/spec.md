# SPEC-018：GitHub私有仓库准备

2026-10-23。用户选择先准备私有仓库，许可证仍未选定；本增量不创建远端、不推送、不公开或发包。目标是补齐可移植测试入口、私有仓库CI配置及待提交文件检查，并给出明确就绪结论。

标准库scripts/check.py统一组件/接入测试；默认不加载PG集成，--postgres要求显式专用数据库且任何skip均失败，临时schema由现有测试管理。报告保存在忽略目录。CI在Ubuntu/Python3.12/PostgreSQL16运行全部Python测试，独立Node22任务测试/构建Dashboard，无真实模型凭证；CI仅配置，本机不冒充GitHub已运行。

scripts/repository_check.py检查Git实际候选文件（tracked+非忽略untracked），拒绝缓存/venv/运行产物/配置密钥文件以及常见凭证模式，不打印敏感匹配文本；不扫描sources镜像、不运行Agent、不修改索引。仅有限静态检查，不能证明不存在所有秘密；已有历史/远端不在扫描范围。公开发布仍需单独选许可证。

AC1801：候选文件和故障夹具检查，无泄漏/不改索引；忽略产物不进入候选集。
AC1802：统一入口无skip误报，实际本机全Python含真实PG与前端回归；CI配置与本地命令一致。
AC1803：私有初期开发版本/公开/包发布状态分开，许可证保持未定，发布清单和机器证据可复核。私有上传就绪后主动告知用户。
