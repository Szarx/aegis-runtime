# SPEC-021：治理事件离线排查包

2026-10-23，已验证。完整场景：按条件从已有Collector导出已接收事件，离线查看JSONL/CSV、按结果汇总，再核验文件完整性。服务与SDK均不依赖LLM，不增加接口/迁移/依赖。

CLI scripts/security_export.py提供export/verify。export使用已有Trace token与020分页接口，筛选与020一致，默认上限1000、最大10000行；默认查询开始时间上界为本机开始导出的纳秒时间。默认每页100，禁止重定向，HTTP限时与限体积；仅HTTPS或本机回环HTTP，URL不带认证/查询/片段。凭证只从AEGIS_API_TOKEN读取，不写文件/日志。

只接受020完整白名单及严格ID/纳秒/原因/结果配对。跨页total变化、重复或乱序、异常分页、超过上限、协议/网络失败均失败关闭；无自动重试、静默截断或续传。即使这些检查通过，跨页仍不是数据库快照，导出不是认证或完整审计。

新目录独占创建，不覆盖已有目录；写events.jsonl、events.csv及最后提交的manifest.json，失败移除本次创建文件/空目录。中断可留下无有效manifest的残包，verify拒绝。JSONL为无损整数原本，CSV只供查看并转义公式起始文本；电子表格软件仍可能损失数字精度。

manifest格式1包含查询条件、时间、行数、结果/原因汇总、文件SHA-256/长度、并发及信任局限，不含源URL/凭证。verify只读取固定三个文件、拒绝符号链接/超限，验证哈希、JSONL形状/排序/重复与CSV和汇总一致；清单可被重新生成，哈希不提供来源认证或防篡改。

AC2101：协议/范围/路径/错误隐私/分页完整性、独占输出与失败清理。
AC2102：JSONL精度、CSV安全、摘要与离线核验、篡改/残包拒绝。
AC2103：真实HTTP/PG导出多页与过滤、离线verify，无LLM；文档示例、原契约回归和机器证据。
