# SPEC-029：统一数据工作台视觉与页面质量

2026-10-26，已验证。用户要求参考优质前端项目，减弱模板化/宣传式视觉，优化全部前端页面。参考官方Supabase数据表格模式、Grafana表格与Langfuse观测产品，整理到resources/notes/frontend-design.md，不复制第三方代码、品牌或整页布局。

范围：统一导航/品牌/字号/颜色/间距/表格/表单/状态/空状态；Trace列表、详情、两类审批、安全事件、连接/错误/加载页面。紧凑深色中性工作台，状态色有语义，去掉装饰编号、标题点、渐变和营销文案；不显示虚构指标。使用本地自绘SVG，不新增字体/CDN/依赖。窄屏保留全部导航，表格局部横滚而非整页溢出，键盘焦点清晰、减少动态遵循系统设置。

原API、时间/Token bigint、白名单内容、会话内凭证、请求取消、人工确认完整参数、决定结果未知不重试等协议保持。仅视觉与文案，审批按钮与请求条件不降级。服务不可达时明确显示错误，不用假数据伪造在线状态。浏览器验收用隔离本机真实服务和合成数据，保留原用户页面。

AC2901：全局设计tokens、统一SVG、紧凑导航/排版/数据表格、真实指标。
AC2902：五类业务页和连接/空/错误状态一致，桌面与窄屏可使用、键盘焦点/状态文本不丢失。
AC2903：前端回归、类型检查、生产构建、真实浏览器操作/截图，原API/安全边界保持；参考来源与验收记录可追溯。
