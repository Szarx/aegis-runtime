# SPEC-032：可重复前端验收入口与生产预览

2026-10-26，已验证。将前端单测、类型、构建及产物核对串为一个本机/CI入口，输出机器结果与日志。验证当前生产bundle经同源代理连接真实隔离服务，保留可查看预览。后续不再仅凭开发热更新声明页面已验收。

scripts/check_dashboard.py使用已安装Node/锁定node_modules，不隐式安装依赖；--node可显式指定，默认查PATH。依次执行Vitest JSON、vue-tsc、Vite，非零/超时/无用例/失败/跳过均失败，不继续伪报成功。每步有界，输出放忽略artifacts；只记录检查日志/计数，不读取模型凭证或联网下载。

构建清单核对index的本地JS/CSS资源存在、路径不越界、无外部CDN入口；保存各JS/CSS字节/gzip/SHA256。预算：入口JS gzip≤50KiB、全部JS原始≤1200KiB、CSS原始≤64KiB，超标失败。这是固定构建预算，不等于下载性能、Lighthouse或安全审计保证。

CI沿用固定Actions/Node22，增加显式Python3.12运行标准库检查器；npm ci仍按锁文件。此轮只本机验证，远端CI另行验收。生产预览用现有Vite preview、原server.proxy配置（已读本地Vite实现确认继承），仅回环监听，不内置凭证或对外发布。浏览器检查hash详情深链、Trace/Token/节点、审批独立连接，记录生产产物而非dev页面。原后端/API/迁移不变。
