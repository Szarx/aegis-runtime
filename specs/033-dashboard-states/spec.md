# SPEC-033：真实加载、刷新与失败恢复状态

2026-10-26，已验证。继续完善工作台：路由异步模块加载时有明确占位和失败恢复；数据刷新时区分旧结果和新查询，审批加载期间不把未知显示成零。遇到错误不给虚构成功状态、不自动重复审批决定。

异步页面共用加载/错误组件，120ms后显示静态占位，15秒模块超时，加载失败不自动循环重试；只显示固定安全文案，不回显异常消息/地址。用户可显式重新加载页面，并提示这会清除会话内凭证。不会自动登录或提交决定。

Trace同条件刷新可暂时保留旧结果，但标注“正在刷新，暂时显示上次结果”；应用新条件或翻页先清掉旧结果，避免把旧页配到新条件。记录的是页面查询完成时间，不冒充服务端最新事件时间。失败显示原安全错误与手动重试；会话仍在并不代表服务持续健康。审批载入/提交时计数显示未知，不展示虚构0，确认仍重置。

AC3301：模块失败安全文案/显式恢复，不自动重试或泄漏原异常。
AC3302：刷新/新筛选/失败/重试状态真实，审批未知计数不变0，原请求取消/防旧响应提交契约保持。
AC3303：前端/构建质量入口、受控本机延迟/503浏览器验收与记录，无生产API故障开关或授权变化。
