# SPEC-034：阅读对比度、触控目标和焦点质量

2026-10-26，已验证。基于官方WCAG2.2解释资料核对工作台阅读质量，保持中性视觉：修正偏暗辅助文字，统一受测文本tokens；扩大小型复制/密度/文本操作命中区域，复核跳转主要内容、节点键盘和窄屏布局。参考记录追加resources/notes/frontend-design.md。

受测普通文本tokens在已声明背景上的对比度至少4.5:1，状态文字同样测量；焦点强调色相对画布至少3:1。小型主动控件目标至少26×26px，审核确认标签至少32px高；不以此声明整站WCAG认证、屏幕阅读器完整兼容或所有动态图表自动合规。状态仍有文字，不能仅凭颜色区分。

不改变任何凭证、审批确认、API、未知数据、密度持久化策略或业务行为。不改变操作系统/浏览器辅助功能设置。浏览器实际验证焦点、尺寸、窄屏无整页溢出和文本配色，记录覆盖范围。

AC3401：受测tokens/语义状态对比度和回归检查。
AC3402：复制/密度/文本操作目标与审核标签、跳转主要内容和节点焦点。
