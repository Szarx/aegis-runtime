# SPEC-041：私有开发快照统一验收

2026-10-28，设计冻结。一个本地命令顺序检查pip依赖、有限仓库候选、全部Python/真实专用PostgreSQL、前端测试/类型/构建/预算，生成独立机器报告。依赖已安装，不安装/升级、不调用真实模型、不创建远端或发布。

AC4101：必须显式--postgres并提供专用AEGIS_TEST_DATABASE_URL；Node显式路径或PATH。输出仅在仓库artifacts内的新目录，已有目录/符号链接拒绝，不覆盖历史报告。检查前后计算Git跟踪及非忽略untracked候选文件的SHA256摘要；有变化则失败。摘要只描述工作树字节，不覆盖Git历史、暂存差异、依赖缓存或全部秘密。

AC4102：复用现有检查器。Python新增兼容默认的--output选项，使独立结果不会复用历史artifacts/check。任何阶段失败/超时/缺报告/skip/零测试/不一致汇总均失败且不继续下一阶段。各阶段独立stdout/stderr日志，不在总报告复制命令、环境、数据库URL或私密异常。日志为本机诊断内容，不保证第三方工具绝不输出秘密。

AC4103：Python必须六套件全部通过且数量合计一致；前端必须实际完整测试、types/build和bundle预算通过。总报告仅保留白名单计数、阶段状态、起止候选摘要和本机范围。运行中记录阶段状态，退出0通过/1失败/2预检；不把本机通过当远端CI/生产或公开发布授权。

AC4104：失败/超时/新输出/报告篡改/源变更契约测试、实际全套Python/PG和前端统一运行，私有快照指南与证据。专用schema由原测试清理，保留原UI数据。连续开发恢复，但本SPEC通过前不开始下一项。

环境故障修正：实际首跑遇到Docker引擎停机。Python --postgres入口增加3秒只读连接/SELECT 1预检，失败固定退出2，不输出连接串/异常正文，避免进入整套数据库测试后反复等待。原未做预检的首次运行保留观察到终态，不将缺数据库的结果当通过。统一入口另核对候选计数和前端实际资源哈希，防止完整receipt与当前构建不一致。
