# SPEC-043：可复现的列表查询地址

2026-10-29，设计冻结。Trace列表和安全事件列表的已应用条件/20条分页进入hash地址，刷新与独立会话认证后恢复；新增标题栏复制查询链接。草稿不进入链接，复制无需请求。参考Grafana内部链接的保存查询状态/独立授权模式：https://grafana.com/docs/grafana/latest/visualizations/dashboards/share-dashboards-panels/ 。本地实现不提供公开访问或持久保存的服务端查询。

AC4301：独立纯函数限定两列表路由、固定字段与顺序、非负20倍offset<=10000、标识/长度/枚举/时间边界。时间在URL中为规范UTC ISO毫秒，跨时区打开保留绝对边界；草稿显示当前本地时间，未改时间再次应用保留原绝对值。拒绝未知/重复/非法编码/过长参数，不把无效链接悄悄执行为全部数据查询。旧无参数地址、Trace/Span深链与审批路由保持。

AC4302：应用/清空/分页建立历史项，前进后退恢复条件、页码与草稿，取消旧请求且迟到结果不能覆盖新地址。同一地址应用可显式刷新。列表进入详情后后退恢复列表；初次认证与连接过程中的地址变化以当前合法地址为准。无效链接显示恢复入口，不发送列表查询；重新认证使用合法查询的条件，token不写入URL或存储。

AC4303：两列表共用CopyValue复制反馈和失败手动文本，标题栏窄屏可换行，键盘可达。复制规范地址删除来源URL的userinfo/search/hash，白名单字段不包含任何凭证。链接包含上报身份/服务/工具等查询元数据，界面简短说明包含已应用条件，文档提醒按工作区范围分享；不是结果快照，新数据可能改变页边界。

AC4304：纯函数/边界/UTC往返/非当前草稿与受影响前端回归、类型/生产构建/预算；真实Collector/PG/production preview验证两页应用/分页/复制/刷新重新认证/历史导航、无效地址、390px和键盘。协议/SQL/依赖/审批授权保持，Python证据继承042，只有前端重跑不冒称完整后端回归。
