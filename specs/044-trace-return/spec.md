# SPEC-044：关联Trace与来源查询返回

2026-10-29设计冻结。补全043的列表→详情→显式返回闭环：从Trace列表进入详情保存已应用查询/20条分页；从安全事件进入详情同时定位事件Span并保存事件查询。详情、加载和错误状态的返回入口恢复来源；刷新或独立会话重新认证后仍可返回。仅使用hash导航与已有查询，不新增API/SQL/依赖。

AC4401：Trace地址追加可选return参数，只接受queryLocation白名单的两种列表地址，规范化字段/UTC边界/offset，拒绝未知/重复/坏编码、外部地址、嵌套详情或审批地址。Trace/Span严格非零小写hex保持；旧地址与现有节点复制输出保持。最大地址16384字符，来源查询原有4096限制保持。返回地址不是任意URL跳转、授权或结果快照。

AC4402：Trace列表的文字/箭头链接都带已应用来源；事件关联链接带事件Span和已应用来源，草稿不传递。详情显示“返回执行追踪”或“返回安全事件”，加载/查询失败也有同一入口。节点选择/键盘/耗时排行定位保留return且不重复请求同Trace。独立的“复制节点链接”继续只包含Trace/Span，不传播来源查询元数据。

AC4403：无来源默认返回基础Trace列表；合法来源可经刷新认证或独立会话保留，列表重新查询恢复页码/表单。浏览器后退仍可用。无效return使详情地址无效且不请求其Trace详情，不静默采纳外部地址。审核令牌/操作/参数确认、工具执行语义保持；审批页面原有Trace链接不隐式增加来源。
