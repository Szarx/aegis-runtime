# SPEC-049 运行与采集健康

- AC4901 SDK 显式启用独立健康上报，业务线程只更新有界内存状态。记录实例 ID、递增序号、当前活动 Span 数、最多 16 条活动 Trace 标识及既有累计采集诊断。默认关闭，不改变旧 OTLP。
- AC4902 Collector 单进程保存最多 1024 个实例的最新快照，完整校验并拒绝未知字段。旧序号不更新新鲜度。按服务端接收时间判断心跳正常或中断，中断不推断业务失败。Collector 重启后快照重新建立。
- AC4903 Dashboard 提供独立健康页，查看队列、丢弃、导出失败、上报失败、活动 Trace 和快照新鲜度。活动 Trace 尚未上报完整 Span 时保留原详情缺失提示。查询失败保留上次快照并明确说明。
- AC4904 真实 HTTP 验证运行中可见、结束后活动清零、陈旧序号、失联与错误上报。测试 SDK 有界队列与健康线程生命周期，前端严格解码、刷新和失联显示。

本轮是单 Collector 的临时健康快照。历史审计、持久健康存储、多副本一致性和业务执行结果恢复需各自设计。
